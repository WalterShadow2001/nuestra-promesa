# Carpeta de Galería

Coloca aquí tus fotos y videos para que aparezcan automáticamente en la animación.

## Formatos soportados

### Imágenes
- `.jpg`, `.jpeg`
- `.png`
- `.webp`
- `.gif`

### Videos
- `.mp4`
- `.webm`
- `.mov`

## Cómo se ordenan

Los archivos se ordenan alfabéticamente. Si quieres un orden específico, nómbralos así:
- `01-para-siempre.jpg`
- `02-nuestro-comienzo.jpg`
- `03-el-si.mp4`
- `04-felices-por-siempre.jpg`

## Cómo subir archivos

### Opción 1: Desde la web
Abre la animación y haz click en el botón **+** en la esquina superior derecha.
Selecciona los archivos y se subirán automáticamente.

### Opción 2: Desde GitHub
Sube los archivos directamente a esta carpeta desde:
https://github.com/WalterShadow2001/nuestra-promesa/upload/main/public/images/gallery

### Opción 3: Reemplazo directo
Reemplaza los archivos `foto1.jpg` ... `foto5.jpg` con tus propias fotos,
manteniendo los mismos nombres.

## Captions automáticos

Si tienes 5 fotos o menos, se asignan estos captions en orden:
1. "Para siempre"
2. "Nuestro comienzo"
3. "Un sí para siempre"
4. "Nuestra historia"
5. "El sí"

Si tienes más de 5 fotos, los captions se ciclan.

Si quieres captions personalizados, nombra el archivo con el caption:
- `Para siempre.jpg`
- `Nuestro comienzo.mp4`

Y se usará el nombre del archivo (sin extensión) como caption.
